# Background Images

Place your Nataraj murti or Bharatanatyam wallpaper image here.

## Instructions:

1. **Save your image** in this folder (`static/images/`) with one of these names:
   - `nataraj-background.jpg`
   - `nataraj-background.png`
   - `bharatanatyam-background.jpg`
   - `bharatanatyam-background.png`

2. **Recommended image specifications:**
   - Format: JPG or PNG
   - Size: 1920x1080 or larger (for high quality)
   - File size: Under 2MB (for faster loading)

3. **Update the CSS** if you use a different filename:
   - Open `static/style.css`
   - Find the line with `url('/static/images/nataraj-background.jpg')`
   - Change the filename to match your image

## Where to find images:

- Search for "Nataraj statue" or "Bharatanatyam dancer" images
- Use royalty-free images from sites like:
  - Unsplash.com
  - Pexels.com
  - Pixabay.com

## Note:

If no image is found, the page will use a beautiful gradient background as fallback.
